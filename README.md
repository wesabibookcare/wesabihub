# OmorfiHub

Nigeria's trusted Pick-Up & Drop-Off (PUDO) network that connects Customers, Merchants, E-commerce Platforms, Logistics Partners, and Verified Neighborhood Centers through one secure platform.

## User Roles
1. **Customer**: Sends and receives parcels.
2. **Merchant**: Small businesses using verified centers as nationwide pickup locations.
3. **OmorfiHub Center Owner**: Verified neighborhood businesses (Filling stations, Supermarkets, etc.).
4. **Center Staff**: Staff members handling parcels at the centers.
5. **Logistics Partner**: Transports parcels between centers.
6. **Platform Admin**: Platform management and oversight.

## Design System Principles
- **Clean & Premium**: Emphasize simplicity, trust, speed, professionalism, accessibility, and consistency.
- **No Clutter**: No confusing menus, no unnecessary animations.
- **Responsive**: Desktop first, tablet friendly, mobile responsive.
- **Color Palette**: Deep forest greens for trust (Primary), Slate grays for typography and borders.

## Future-Ready Architecture
- Designed for Firebase integration (Auth & Firestore) in later stages.
- Ready for Escrow, API integrations (Jumia, Konga), QR scanning, OTP verification, Maps, Notifications, and Payments.
- Client-side routing set up with `react-router-dom`.
- Reusable UI component strategy in `src/components/ui`.
